📖 1. Project Overview

WaveLock is an enterprise-grade multimodal biometric authentication system engineered to solve the hardest problems in touchless physical security: shoulder-surfing imitation, identical twin / sibling presentation attacks, and impostor replay attacks.

Unlike conventional single-factor systems (which rely solely on facial recognition or simple gesture classification), WaveLock couples two orthogonal human biometric layers into a unified 4-Stage Cascade:

👤

Stage 1: Face Identity Anchor

YuNet detector + SFace deep embedding network verify physiological identity at 112×112 resolution.

🛡️

Anti-Sibling & Lookalike Floor

Elevated cosine threshold (θ = 0.530) and lookalike detection floor (0.400) reject genetic mimics.

🖐️

Stage 2: Macro Gesture Gates

4 hard gates (DTW, Finger State, Order Transition, Segment Max) verify the behavioral password.

🦴

Stage 3a: Hand Orthometrics

5 scale-invariant skeletal phalanx bone ratios verify biological hand morphology.

⚡

Stage 3b: Neuromotor Kinematics

Dimensionless jerk (J_dim ≤ 1.75) and velocity envelope fluidity verify involuntary motor dynamics.

⚖️

Stage 4: Multimodal Consensus

Triple-score fusion (S_multi) enforces cross-modal consensus before granting access.

🛡️ 3. The 4 Verification Stages

Stage 1: Face Identity Anchor (Physiological Subsystem)

Employs YuNet (a lightweight 85KB ultra-fast neural face detector) and SFace (a 128-dimensional deep feature representation model) running natively on CPU via OpenCV DNN.

  • Uniform Temporal Sampling: Samples 6 frames evenly distributed across the gesture duration (t = 0, 12, 24, 36, 48, 59) to prevent static photo replay or mid-gesture impersonator handoffs.
  • Feature Extraction: Each face is aligned to a canonical 112×112 coordinate space using 5 facial landmarks (eyes, nose, mouth corners) and transformed into an L2-normalized 128-D vector.
  • Cosine Similarity Metric: Compares sample embeddings against the enrolled master template face_embedding.npy: 
    Cosine Similarity = (E_auth • E_reg) / (||E_auth|| • ||E_reg||)

Stage 2: Macro Gesture Dynamics (Behavioral Subsystem)

Evaluates the 60-frame normalized gesture trajectory against registered templates across 4 strict gates:

GateAlgorithmEnforced LimitAttack Prevented
Gate 1: DTW DistanceFast Dynamic Time Warping with Euclidean metricAuto-calibrated via MADDifferent spatial movements or gross trajectory deviation
Gate 2: Finger State MismatchContinuous joint angles: MCP, PIP, DIPAuto-calibratedWrong finger configurations or static postures
Gate 3: Order TransitionLevenshtein edit distance on finger state transitionsAuto-calibratedOut-of-order execution (e.g. 1-3-2-4 instead of 1-2-3-4)
Gate 4: Segment Max MismatchWorst-of-6 discrete temporal windows (10 frames each)Auto-calibratedBrief 300ms imitation or momentary spoof attacks

Stage 3: Hand Orthometrics & Neuromotor Kinematics

Guarantees that an observer who learned the gesture password cannot authenticate using their own hand:

  • Stage 3a: Hand Orthometrics (Bone Ratios): Extracts 5 anatomically invariant skeletal length ratios (Thumb/Palm, Index/Palm, Middle/Palm, Ring/Palm, Pinky/Palm) aggregated via frame-wise median over 60 frames. Because ratios are invariant to camera distance and zoom, an impostor with different finger proportions is rejected even if unit-sphere scaled.
  • Stage 3b: Neuromotor Kinematics (Jerk & Fluidity): Calculates the third derivative of motion (rate of change of acceleration) normalized as Dimensionless Jerk: 
    Jerk Ratio = MAJ_live / MAJ_baseline ≤ 1.75 (where MAJ = mean(|d²v/dt²|))
    Natural human motor memory produces smooth, bell-shaped velocity profiles (J_dim ≤ 1.75), whereas an impostor visually guiding their fingers exhibits elevated jerk (J_dim ≥ 2.5) and low velocity fluidity.

Stage 4: Multimodal Decision Consensus & Score Fusion

Computes an overarching cross-modal confidence score combining face identity, macro gesture fidelity, and hand biometrics:

S_multi = 0.40 • S_face + 0.35 • S_macro + 0.25 • S_hand_bio

Decision Policy: Access is GRANTED if and only if:

  1. Face Cosine ≥ SFACE_COSINE_THRESHOLD (0.530)
  2. All 4 Stage 2 Macro Gesture Gates PASS
  3. Hand Orthometrics Difference ≤ Calibrated Tolerance
  4. Dimensionless Jerk ≤ 1.75
  5. Fused Multimodal Confidence S_multi ≥ 0.650

👥 4. The Anti-Sibling / Lookalike Presentation Attack Defense

⚠️ The Sibling Confounder & Spectacle Occlusion
Siblings share ~50% identical genetic markers. Under the default OpenCV SFace threshold (0.363), an authentic user scored 0.70–0.85, but a sister with her hair tied back scored 0.65–0.70. When wearing the authentic user's spectacles, periocular occlusion and identical frame geometry pushed the sister's score to 0.75 (cosine ~0.53), causing a false acceptance!

WaveLock deploys a dual-threshold anti-sibling defense:

  1. Elevated High-Security Threshold: SFACE_COSINE_THRESHOLD = 0.530 (equivalent to 75% display match). Unrelated strangers typically score 0.05–0.25; siblings peak at 0.529.
  2. Lookalike Sibling Detection Floor: SFACE_LOOKALIKE_FLOOR = 0.400. When an attempt falls into the range [0.400, 0.529], the system triggers an explicit Amber HUD Warning: 
    [ALERT] Potential Sibling/Lookalike Presentation Attack Detected (Score: 71.2%)
  3. Multi-Frame Burst Enrollment: Face registration captures 5 distinct frames, extracts L2-normalized embeddings, and stores the unit-normalized mean vector to eliminate single-frame expression or lighting bias.
  4. Zero-Tolerance Aging Isolation: Adaptive template aging strictly updates hand gesture templates on high confidence (≥ 85%) but never modifies face_embedding.npy, preventing gradual biometric drift.

🧩 7. Core Modules Reference

gesture_auth.py

Orchestrates real-time authentication. Initializes both MediaPipe Hands and YuNet/SFace. In the idle state, renders a color-coded facial tracking box (Green ≥ 0.530, Amber = Sibling Alert, Red < 0.400). During recording, buffers clean camera frames alongside hand landmarks. Executes the 4-Stage cascade and overlays a detailed 4-line diagnostic HUD.

gesture_capture.py

Guides the user through the 2-Stage enrollment pipeline: Stage 1 records a 5-frame facial burst to compute the master face_embedding.npy; Stage 2 records 5 valid gesture repetitions, applies quality gates, computes statistical thresholds, and stores user profiles.

utils/face_auth.py

Encapsulates face detection and recognition using OpenCV's native ONNX runtime. Provides FaceAuthenticator with methods detect_and_align(), extract_embedding(), compute_similarity(), and verify_face_frames().

utils/anthropometrics.py

Computes 5 skeletal bone-length ratios from hand landmarks (Thumb/Palm, Index/Palm, Middle/Palm, Ring/Palm, Pinky/Palm), median-filtered across 60 frames. Evaluates Euclidean deviation against enrolled profile tolerance.

utils/kinematics.py

Computes velocity, acceleration, and jerk profiles. Normalizes kinematic smoothness using Dimensionless Jerk (J_dim) and velocity envelope fluidity to separate natural muscle memory from visual imitation.

🚀 9. Setup & Usage

1. Install Dependencies

pip install -r requirements.txt

2. Register a New User (Face + Gesture)

python gesture_capture.py

Enter your username. The system will first capture your face, then prompt you to perform your gesture 5 times.

3. Authenticate

python gesture_auth.py

Enter your username. The camera will track your face (Green box indicates verified identity). Press [R] to record and perform your gesture.

4. Camera Diagnostics & Selection

python gesture_auth.py --list-cams
python gesture_auth.py --camera 1

WaveLock automatically prioritizes external USB webcams (Index 1) over internal laptop cameras (Index 0). Use --camera <index> to override.

5. Run the Multimodal Security Benchmark

python evaluate_multimodal_security.py --user saimani

Executes the 180-trial adversarial benchmark against all 6 threat cohorts and outputs the formal empirical security report.
