📖 1. Project Overview

WaveLock is a real-time, webcam-based biometric authentication system that uses hand gesture recognition as a password. Instead of typing a password, users register a unique hand gesture (e.g., a wave, a sequential finger pattern like "1-2-4-3", or a custom movement) and authenticate by performing that same gesture live on camera.

The system uses MediaPipe for real-time hand tracking, extracts 21 hand landmarks per frame, applies strict spatial and temporal normalization, and evaluates gestures using a robust 4-Gate Security Architecture.

🖐️

Real-time Tracking

MediaPipe detects 21 3D landmarks per hand at webcam speed (~30 FPS).

📝

Multi-sample Registration

Records 5 gesture samples to capture natural variation and create personalized models.

🔢

Auto-calibrated Thresholds

Computes custom limits dynamically from registration data using statistical models.

📐

Dual Normalization

Spatial (position/scale invariant) + Temporal (speed invariant via 60-frame interpolation).

🔒

4-Gate Security

Requires passing DTW Distance, Finger State Avg, Transition Order, and Segment Max Mismatch.

🖥️

Live OpenCV UI

Visual feedback with progress bars, status banners, and detailed pass/fail overlays.

🛡️ 3. The 4-Gate Security Architecture

To prevent false acceptances (e.g., performing a similar but incorrect gesture like "1-2-3" instead of "1-2-4-3"), WaveLock evaluates every gesture across 4 dimensions. A single failure in *any* gate results in access denial.

Gate Description What it prevents
Gate 1: DTW Distance Evaluates the overall 3D trajectory and motion path of the gesture using Dynamic Time Warping. Completely different physical movements.
Gate 2: Finger State Average Mismatch Evaluates whether the correct fingers are extended across the entirety of the 60 frames (measured as an average). Gestures that use the wrong fingers overall.
Gate 3: Finger Transition Order Extracts the exact sequential order of finger movements (e.g., Index Up → Middle Up). Uses Levenshtein edit distance. Incorrect ordering (e.g., "1-3-2-4") or missing steps.
Gate 4: Segment Max Mismatch Divides the 60 frames into 6 discrete 10-frame segments and evaluates the worst segment. Localized spoofing attacks where a gesture is 90% correct but fails in a critical 10% window.

🧩 5. Core Modules

gesture_auth.py

The entry point for logging in. It loads user templates and the config.json, executes the 3-second recording loop, visualizes real-time progress, and triggers the comparison engine. Finally, it overlays granular pass/fail metrics on the webcam feed.

gesture_capture.py

The entry point for registering new users. It guides the user through performing their gesture 5 separate times. It filters out bad captures, requests threshold calibration from the core engine, and saves everything to disk.

gesture_compare.py

The mathematical and security core of the system.

  • DTW Math: compute_dtw_distance()
  • Finger states: compute_finger_state_mismatch(), _joint_angle_degrees()
  • Sequence extraction: extract_finger_transitions(), _levenshtein_distance(), compute_transition_dissimilarity()
  • Segment evaluation: compute_segment_max_mismatch()
  • Threshold calibration: compute_threshold_details()
  • Decision Engine: authenticate_with_details()

utils/normalize.py

  • normalize_spatial(): Subtracts wrist coordinates and divides by maximum Euclidean distance to bound the hand in a unit sphere.
  • normalize_temporal(): Uses scipy.interpolate.interp1d to resample N frames to exactly 60 frames.

⚙️ 6. Configuration Format

The system stores per-user security limits in templates/<username>/config.json:

{
  "threshold": 2.3094,               // Limit for Gate 1 (DTW)
  "finger_state_threshold": 0.2233,  // Limit for Gate 2 (Avg Mismatch)
  "transition_threshold": 0.3657,    // Limit for Gate 3 (Order)
  "segment_threshold": 0.3800,       // Limit for Gate 4 (Segment Max)
  "num_samples": 5,                  // Number of templates stored
  "threshold_method": "statistical_v2", 
  "pairwise_distances": [...],       // Debug data from calibration
  "consistency_score": 74.83         // Score out of 100 based on variance
}

🚀 7. Setup and Usage

Requirements

Python 3.8+ with opencv-python, mediapipe, numpy, scipy, and dtaidistance.

Step 1: Register

python gesture_capture.py

Enter a username and follow the on-screen prompts to perform your gesture 5 times.

Step 2: Authenticate

python gesture_auth.py

Enter your username, press [R] to record, and perform your gesture. The system will display granular pass/fail metrics for all 4 security gates.
