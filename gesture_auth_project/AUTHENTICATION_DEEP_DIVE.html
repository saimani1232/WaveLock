0 Startup & User Profile Loading

When executing python gesture_auth.py, the authentication subsystem loads the registered profile for the specified user from templates/<username>/:

Loaded Biometric Artifacts

  • Face Master Vector: face_embedding.npy (Shape: (128,), L2-normalized float32).
  • Registered Gesture Templates: 5 normalized arrays gesture_1.npy ... gesture_5.npy, each shape (60, 21, 3).
  • Auto-Calibrated Thresholds: config.json containing DTW, finger state, order, segment limits, and calibrated hand morphology tolerance: 
    {
  "threshold": 2.3094,               // DTW Limit
  "finger_state_threshold": 0.2233,  // Finger State Mismatch Limit
  "transition_threshold": 0.3657,    // Order Transition Limit
  "segment_threshold": 0.3800,       // Segment Max Limit
  "anthro_tolerance": 0.0825         // Calibrated Hand Morphology Tolerance
}

1 Model Engine Initialization

Two separate deep learning vision engines run concurrently on the CPU without thread contention:

  • MediaPipe Hands: Configured for video stream tracking with min_detection_confidence=0.7 and min_tracking_confidence=0.5.
  • YuNet & SFace: Loaded via OpenCV DNN from models/face_detection_yunet_2023mar.onnx and models/face_recognition_sface_2021dec.onnx.

2 Live Feed & Real-Time Face HUD

Before recording begins, the camera runs an idle loop providing real-time physiological feedback:

🎨 Real-Time Facial Bounding Box States
  • GREEN BOX: Cosine ≥ 0.530 → Verified Enrolled User (Score: 78.4% — READY).
  • AMBER BOX: 0.400 ≤ Cosine < 0.530 → Potential Sibling / Lookalike Alert.
  • RED BOX: Cosine < 0.400 → Unrecognized Impostor / Stranger.

3 Dual-Stream Synchronous Recording

When the user presses [R], recording activates for exactly 3 seconds:

  • Clean Camera Buffer: Unannotated BGR video frames are buffered into recorded_raw_frames (avoiding OpenCV drawing corruption).
  • Landmark Stream: 21 3D hand coordinates (x, y, z) per frame are buffered into recorded_frames.

4-5 Hand Spatial & Temporal Normalization

To eliminate variation from camera distance and execution speed, raw hand landmarks undergo strict mathematical normalization:

  1. Translation Invariance: Landmark 0 (wrist) is subtracted from all 21 points: 
    L_centered = L_raw - L_wrist
  2. Scale Invariance: All landmarks are divided by the maximum Euclidean norm: 
    scale = max_{i} ||L_{i, centered}||,   L_norm = L_centered / scale
  3. Temporal Invariance: Resampled along the time axis using 1D cubic spline / linear interpolation to exactly 60 frames: 
    Input: (N, 21, 3) → Output: (60, 21, 3)

6 Stage 1: Face Identity Anchor Gate

Physiological Identity Verification

Verifies whether the person presenting the gesture is the authentic owner of the biometric vault.

  1. Uniform Temporal Sampling: Selects 6 unannotated frames evenly spaced across the 60-frame gesture sequence (frames 0, 12, 24, 36, 48, 59).
  2. Face Detection & Landmark Alignment: YuNet locates the face bounding box and 5 facial landmarks (right eye, left eye, nose tip, right mouth corner, left mouth corner), aligning the face to a standard 112×112 chip.
  3. 128-D Feature Embedding: SFace extracts an L2-normalized 128-D vector for each detected face.
  4. Cosine Metric vs Enrolled Master: 
    Cosine Similarity = (E_sample • E_master) / (||E_sample|| • ||E_master||)
  5. Anti-Sibling Threshold Policy:
    • PASS: Cosine ≥ 0.530 (Mean cosine across sampled frames).
    • AMBER LOOKALIKE ALERT: 0.400 ≤ Cosine < 0.530 → Triggers lookalike_sibling_detected = True, preventing shoulder-surfing access by relatives.
    • HARD FAIL: Cosine < 0.400 → Immediate rejection.

7 Stage 2: Macro Gesture Dynamics Gates

Behavioral Gesture Password (4 Hard Gates)

Evaluates whether the physical gesture performed matches the registered behavioral password:

GateEvaluationMathematical FormulaPass Criterion
Gate 1: DTW Distance Global 3D trajectory alignment D(i,j) = ||p_i - q_j|| + min(D_{i-1,j}, D_{i,j-1}, D_{i-1,j-1}) dist ≤ config["threshold"]
Gate 2: Finger State Avg Mean angular extension of 5 fingers θ = arccos((v_AB • v_BC) / (||v_AB|| ||v_BC||)) mismatch ≤ config["finger_state_threshold"]
Gate 3: Transition Order Sequential order of finger movements Levenshtein Edit Distance on symbolic transition string dissimilarity ≤ config["transition_threshold"]
Gate 4: Segment Max Worst-of-6 discrete 10-frame windows max_{k=1..6} [ (1/10) ∑_{t=10(k-1)}^{10k-1} ||p_t - q_t|| ] max_err ≤ config["segment_threshold"]

8 Stage 3: Hand Orthometrics & Neuromotor Kinematics

Stage 3a: Hand Orthometrics (Skeletal Bone Ratios)

Prevents an observer who learned the gesture password from authenticating using their own hand:

  • Extracts 5 scale-invariant phalanx length ratios relative to palm size: 
    R_thumb = L_thumb / L_palm,   R_index = L_index / L_palm,   R_middle = L_middle / L_palm, ...
  • Ratios are computed across all 60 frames and aggregated using the frame-wise median (eliminating MediaPipe tracking noise).
  • Euclidean distance between sample ratio vector and registered profile must be within user tolerance: 
    ||R_sample - R_profile||_2 ≤ Calibrated Tolerance (typically 0.08 - 0.12)

Stage 3b: Neuromotor Kinematics (Jerk & Fluidity)

Measures involuntary neuromotor habits and motor memory fluidity:

  • Dimensionless Jerk: Rate of change of acceleration normalized by movement duration and distance: 
    Jerk Ratio = MAJ_live / MAJ_baseline ≤ 1.75 (where MAJ = mean(|d²v/dt²|))
    Authentic motor memory produces smooth, low-jerk profiles (J_dim ≤ 1.75). Imitators checking their fingers produce jerky, hesitating motion (J_dim ≥ 2.5).
  • Velocity Fluidity: Pearson correlation of velocity envelope against enrolled speed profile (≥ 0.60).

9 Stage 4: Multimodal Decision Consensus

Triple-Score Fusion & Strict Decision Policy

Fuses physiological identity, behavioral macro fidelity, and skeletal hand biometrics into an overall multimodal confidence score:

S_multi = 0.40 • S_face + 0.35 • S_macro + 0.25 • S_hand_bio

Strict Access Grant Rule: Access is granted ONLY when ALL five conditions are simultaneously met:

  1. Face Cosine ≥ 0.530 (Hard identity anchor pass)
  2. All 4 Stage 2 Macro Gesture Gates PASS (Trajectory, Finger State, Order, Segment)
  3. Hand Orthometrics Difference ≤ Calibrated Tolerance
  4. Dimensionless Jerk ≤ 1.75 and Kinematic Fluidity PASS
  5. Multimodal Score S_multi ≥ 0.650

11-12 Security Decision & Anti-Poisoning Aging Lock

Upon successful authentication, the system plays an audio confirmation (or denial buzz). If multimodal confidence is very high (≥ 85%), adaptive template aging updates the stored gesture templates to account for natural drift.

🔒 The Anti-Poisoning Facial Aging Lock
Under no circumstances is face_embedding.npy updated during adaptive aging. Facial embeddings are immutable after enrollment, preventing an impostor or relative from gradually poisoning the master face vector over repeated sessions!

Attempt: Attacker holds a printed photograph or smartphone image of user's face while gesturing.

Outcome: Uniform 6-frame temporal sampling detects identical static facial features across time without micro-expressions or perspective shift; furthermore, physical occlusion of the hand by the photo triggers Gate 1/4 failure. RESULT: ACCESS DENIED.
